# Seed-Test 2.0.0

## Breaking changes

- **Secrets come from `.env`.** `docker-compose.yml` no longer contains secret values. Copy `.env.example` to `.env` and set `ENCRYPTION_SECRET`, `MONGO_ROOT_USERNAME`, `MONGO_ROOT_PASSWORD`, `SESSION_SECRET`, `JIRA_SECRET` and `JIRA_SALT`. Compose refuses to start without them.
- **Upgrading an existing install.** To keep your `seedDB` volume, put these 1.x demo values into `.env`: `MONGO_ROOT_USERNAME=SeedAdmin`, `MONGO_ROOT_PASSWORD=SeedTest`, `SESSION_SECRET=secretSessionKey`, `JIRA_SECRET=secretJiraKey`, `JIRA_SALT=BJ1yJTJ7AFql`. Keep your existing `ENCRYPTION_SECRET`.
- **Changing `JIRA_SECRET`, `JIRA_SALT` or `ENCRYPTION_SECRET`** on an existing database makes stored Jira and AI credentials undecryptable. Users must enter them again.
- **Changing the MongoDB root user** requires updating the user inside MongoDB or recreating the `seedDB` volume, which deletes its data.
- **MongoDB runs as a single-node replica set** (`rs0`) so the backend can use transactions. Existing data is kept. From the host, connect with `directConnection=true`.
- **Production defaults.** The backend image runs with `NODE_ENV=production`. `SESSION_SECRET` is required unless `NODE_ENV` is `development` or `test`. Secure session cookies and trusted proxy headers are on by default. The compose files turn both off for plain HTTP.
- **Node.js** must be 22.22.3+, 24.15.0+ or 26+.
- **Project exports no longer contain AI API keys.** Enter the keys again after an import.
- **Legacy AI configuration is rejected.** Stored flat AI settings return HTTP 400. Save the AI settings again.

## Features

- **Concurrent edits are detected.** Saving a story with an outdated version returns a conflict instead of overwriting newer changes.
- **Story download** button in the story header.
- **Read-only projects.** Members without edit rights no longer see rename, delete or download actions.
- **Warning before leaving unsaved scenario edits.**
- **Confirmation before deleting a report.**

## Fixes

- **No more lost updates.** Stories, scenario lists, story order and groups save atomically. A stale tab no longer overwrites server-owned fields such as `lastTestPassed` and `issue_number`.
- **Project import works on every MongoDB.** Invalid archives are rejected with HTTP 400 before anything is written. Imported projects belong to the importing user.
- **Blocks stay in their project** on rename and import.
- **Security.** Closed a GitHub merge account takeover and IDOR gaps in story and group writes. The GitHub OAuth callback checks state. GitHub tokens are encrypted at rest. Password reset links expire after one hour, and reset mails no longer reveal whether an account exists.
- **Legacy passwords** migrate on the next login instead of locking the account out.
- **Duplicate names and emails** return HTTP 409 instead of a server error. Unique indexes protect them.
- **Rate limits.** Global limit of 100 requests per minute per IP on `/api`. Too many requests show a notice instead of redirecting to login.
- **Editor and UI fixes.** Creating a project no longer freezes the page. The chosen scenario and run status survive updates. Escape closes the help menu. Whitespace-only names are rejected. The Jira authentication method is corrected.

## Internal

- Playwright E2E suite for the core flows (`e2e/`, see `docs/testing.md`).
- Integration tests with Testcontainers for persistence races, retries and indexes.
- Zod v4 validation on all backend routes and central config validation at startup.
- Angular 22 with zoneless change detection. UIkit is replaced by Angular Material.
- Express 5. Strict ESLint with zero errors and zero warnings in backend and frontend.
